# Sentiment Analysis of Product Reviews

This project implements **Natural Language Processing (NLP)** techniques to analyze customer sentiment from a dataset of 400 product reviews.

#Key Features
* Data Preprocessing: Cleans raw text by converting to lowercase, removing punctuation, and filtering out stop words to improve analysis accuracy.
* Sentiment Classification: Utilizes the **TextBlob** library to calculate polarity scores, categorizing each review as "Positive", "Negative", or "Neutral".
* Statistical Insights: Generates a final report on customer satisfaction distribution[cite: 2].

#Objective
The goal of this assignment is to extract valuable insights from unstructured human communication, demonstrating the practical application of NLP in business strategy.
